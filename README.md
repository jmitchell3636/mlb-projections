# 2027 MLB Projections

Player and team projections for the 2027–2031 MLB seasons by Jake Mitchell.

**View the site:** https://jmitchell3636.github.io/mlb-projections

**Aging curves & comps:** https://jmitchell3636.github.io/mlb-projections/lab.html (archetypes, the aging the projections imply for each, and nearest-profile comps, all derived from the same frozen projections)

Built entirely from public data:
- [Lahman Baseball Database](https://sabr.org/lahman-database/) (CC BY-SA 3.0)
- [Chadwick Bureau Register](https://github.com/chadwickbureau/register) (ODC-By 1.0)
- [Baseball Savant](https://baseballsavant.mlb.com) / Statcast, © MLB Advanced Media, used for non-commercial analysis

This repository contains only the published page. The projections were frozen on October 14, 2026, before the 2027 season; the commit history shows any later change.
