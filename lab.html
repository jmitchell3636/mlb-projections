How archetypes are defined

Method. Archetypes: k-means clustering on each player's standardized 2027 rate profile, fit on regulars and then applied to everyone, with names assigned by rules on the cluster centers (most steals = Speed, fewest strikeouts = Contact, and so on). High-strikeout hitters must also have above-median ISO to count as power; the rest form Swing-and-miss, no power. Aging curves: the change from one projected season to the next for every player, 2027 to 2031. Longer horizons also pull every projection toward the league average, so that pull is estimated (one slope per year step, alongside age effects) and removed first; what remains is smoothed by age, chained into a curve, and anchored to the archetype's average level. These curves show how the model ages players, not a separate study of historical aging. Comps: weighted distance across the standardized profile stats listed in the key; the map is a two-dimensional principal-component view of the same profiles. Data credits as on the main page.
